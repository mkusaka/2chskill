# 今北産業

入力を読み、読み手が最初に知るべきことを三行に圧縮する。

1. 何の話か、または結論を書く。
2. 重要な経緯・原因・対立を書く。
3. 現在地、影響、次の動きを書く。

事実、当事者の主張、推測、反応やネタを混ぜない。情報が足りない箇所は補わず、「不明」「要確認」と書く。投稿の繰り返しや枝葉の反応はまとめるが、結論を変える反証は残す。

基本形:

```markdown
## まとめ
- 話題・結論:
- 経緯・理由:
- 現在地・影響:
```

必要な場合だけ、三行の後に `## 要確認` と `## ref` を追加する。要約のために勝手に検索せず、入力に含まれる出典はリンクやレス番号を保つ。
