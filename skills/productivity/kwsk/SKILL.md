# kwsk

全体を再要約せず、指定された一論点を詳しくする。最初に答えを置き、必要な分だけ背景と具体例を足す。

- 対象の論点と、対象外の話を決める。
- 結論を一文で示す。
- 背景、仕組み・因果、具体例の順に説明する。
- 確認できる事実と推測を分ける。
- 元文のリンク、レス番号、引用箇所があれば対応づける。

```markdown
## 結論

## 背景

## 仕組み・理由

## 具体例

## 注意点
```

関係のない論点を広げない。根拠がない細部や、もっともらしい補足を創作しない。指定がなければ、専門用語には短い言い換えを添える。
