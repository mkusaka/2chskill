# 根拠の照合

文章を要約するのではなく、重要な主張が何に支えられているかを明らかにする。

- 重要な主張を一文ずつに分解する。
- 各主張を「確認できる事実」「当事者の主張」「推測・解釈」「反応」に分類する。
- 直接の根拠、二次情報、推論、根拠なしを区別する。
- 根拠が主張をどこまで支えるかを「支持」「一部支持」「反証あり」「未確認」で示す。
- 出典の存在と、その出典が主張を裏づけることを混同しない。

```markdown
| 主張 | 種類 | 根拠 | 判定 | 不確実性 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
```

表の後に、判断の要点と追加で必要な証拠を書く。リンク、レス番号、文書名、引用箇所を可能な範囲で残す。根拠がない主張は、もっともらしく補完せず「未確認」とする。
