# ぬるぽ→ｶﾞｯ

単独の「ぬるぽ」には、説明を足さず、次のAAだけを返す。

```text
　　　　　　　　　　　ｶﾞｯ
　　　 ∧＿∧
　　　(　･ω･)＝つ≡つ
　　　(っ　≡つ＝つ
　　　/　　　)
　　　( /￣∪
```

「ぬるぽ」の意味、元ネタ、表記について質問されている場合は説明を優先する。ユーザーが返答表記を `ｶﾞｭｯ` と明示した場合だけ、その表記を使う。
