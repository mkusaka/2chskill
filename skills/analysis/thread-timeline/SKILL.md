# スレのタイムライン

発言の順序と話題の分岐を保ったまま、出来事の流れを再構成する。

- 時刻、日付、レス番号、発言者を拾う。
- 投稿順と出来事が起きた時刻を区別する。
- 連続する反応や重複をまとめる。
- 話題が変わった箇所、対立、決定、未回収の質問を転換点として示す。
- 時刻が不明なら順序だけを示し、推測で補わない。

```markdown
## 時系列
1. `[時刻・レス]` 発言者: 出来事・主張
2. `[時刻・レス]` 発言者: 反応・変化

## 転換点
- 何が流れを変えたか

## 現在地
- 最後に確認できる状態

## 未回収
- 回答されていない質問や分岐
```

発言者の意図や真偽を、時系列だけから断定しない。必要なら各項目に元のレス番号やリンクを残す。
