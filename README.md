# 2chskill

2ちゃんねる・匿名掲示板の言い回しを入口に、文章の整理と理解を助けるAgent Skillsです。

## Install

```sh
npx skills add mkusaka/2chskill
```

特定のスキルだけ追加する場合:

```sh
npx skills add mkusaka/2chskill --skill imakita-sangyo
```

## Skills

- `imakita-sangyo`: 長文やスレの流れを三行で要約
- `kwsk`: 一つの論点を詳しく説明
- `haradei`: 画像・URL・原文・根拠を提示
- `ggrks`: 検索して出典つきで調査
- `thread-timeline`: スレや会話を時系列で再構成
- `source-wa`: 主張と根拠を対応づけて検証
- `nulpo`: 「ぬるぽ」にAAつきで「ｶﾞｯ」と返す
